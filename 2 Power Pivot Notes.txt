  VAR __DS0Core = 
    SUMMARIZECOLUMNS(
      ROLLUPADDISSUBTOTAL(ROLLUPGROUP('Apr 2016'[WDayNum], 'Apr 2016'[WDay]), "IsGrandTotalRowTotal"),
      "SumAmount", CALCULATE(SUM('Apr 2016'[Amount]))

--IF()

IF function is used to check the given expression is either True or False. 

Syntax-IF(LogicalTest, ResultIfTrue, [ResultIfFalse])

	If the expression results TRUE then second argument will return, otherwise third argument will return.

	The last argement in Square Brackets is optional, If you are not providing this i.e. if the condition is not satisfied it will return NULL values. 

Ex1: SalRange = IF(Emp[SAL]<1500, "LowSal")
Ex: Sal.Range = IF(Emp[SAL]<1500,"MinSal", "HighSal")

Ex1: SalRange = IF(Orders[Sales]<100,"Low Sales", IF(Orders[Sales]>300, "High Sales", "Avg Sales"))

Ex2: SalCategory = IF(Emp[SAL]<1000, "Low Sal", IF(Emp[SAL]>=3000, "High Sal", "Med Sal"))

ALL Functions

1. ALL( )
ALL Function will Returns all the rows in a table, or all the values in a column, ignoring any filters that might have been applied.
i.e It ignores inside filters as well as out side filters.

Syntax: ALL ( [<TableNameOrColumnName>] [, <ColumnName> [, <ColumnName> [, … ] ] ] )

Ex1: All.RegionCol = CALCULATE(SUM(Orders[Sales]), ALL(Orders[Region]))  i.e for all the values in a column (Region)

Ex2: All = CALCULATE(SUM(Orders[Sales]), ALL(Orders)) i.e for all the values in a Table (Orders)

Sales % All = DIVIDE(Orders[SumOfSales], [All])


2. AllSelected( )
ALL Selected Function will Returns all the rows in a table, or all the values in a column,
ignoring any filters that might have been applied inside the query, but keeping filters that come from outside.

i.e: It Keeps only out side filters.


Ex1. AllSelected = CALCULATE(Orders[SumOfSales], ALLSELECTED(Orders))
Sales% AllSelected = DIVIDE(Orders[SumOfSales], [AllSelected])


3. AllExcept( )

When we are dealing with hierarchical data, The requirement is to calculate % of the parent total. Then it will be used.

Ex1. AllExcept = CALCULATE(Orders[SumOfSales], ALLEXCEPT(Orders, Orders[Category]))
Sales% AllSelected = DIVIDE(Orders[SumOfSales], [AllSelected])

------- Mathematical & Statistical Functions.

--- Mathematical Functions.

- INT(): It rounds a number down to next integer.

Ex: Int.ShippingCost = INT(Orders[Shipping Cost])

- ROUND(): It rounds to a number to the given No.of digits.

Ex1: Round.ShipCost = ROUND(Orders[Shipping Cost], 0)
Ex2: Round.ShipCost = ROUND(Orders[Shipping Cost], 1)


- ROUNDUP(): It Rounds a number to next integer value, If No.of digits=0.

Ex1: RoundUp.ShipCost = ROUNDUP(Orders[Shipping Cost], 0)
Ex2: RoundUp.ShipCost = ROUNDUP(Orders[Shipping Cost], 1)

- ROUNDDOWN(): It Rounds a number to integer value, If No.of digits=0.

Ex1: RoundDown.ShipCost = ROUNDDOWN(Orders[Shipping Cost], 0)
Ex2: RoundDown.ShipCost = ROUNDDOWN(Orders[Shipping Cost], 1)

- DIVIDE(): It performs division and returns alternate result or blank on division by 0.

EX1: SalesByQuantity= DIVIDE(Orders[Sales], Orders[Quantity])
EX2: 200By4= DIVIDE(200, 4)
EX3: 100By0.Blank= DIVIDE(100, 0)
EX4: 100By0.-1= DIVIDE(100, 0, -1)	# Instead of blank, we will get -1.

- EVEN(): It Returns a number roundedup to the next nearest even integer.

Ex1: Even.ShipCost = EVEN(Orders[Shipping Cost])


- ODD(): It Returns a number roundedup to the next nearest Odd integer.

Ex1: Odd.ShipCost = ODD(Orders[Shipping Cost])


- POWER(): It returns the result of a number raised to a power.

EX1: 4Power2= POWER(4,2)= 4^2= 16
EX2: Qty.Power.Qty= POWER(Orders[Quantity], Orders[Quantity])

- SIGN(): It returns 1 If the number is +ve, It returns 0 If the number is 0, It returns -1 If the number is -ve.

Ex: Sign.Profit= SIGN(Orders[Profit])

- SQRT(): It returns Squareroot of a number. And It returns an Error If the number is -ve.

Ex: Sqrt.Profit= ROUND(SQRT(Orders[Profit]), 2)


- FACT(): It returns factorial of a number. And It returns an Error If the number is -ve.

Ex1: Fact.Quantity= FACT(Orders[Quantity])
EX2: FACT(3)= 3*2*1=6

*** What is the difference b/w Sum() & SumX() ?

-SUM(): It adds all the numeric values from a single column. (i.e It allows only single column)

Ex: SumOfSalary= SUM(Emp[Sal])

-SUMX(): It adds all the numeric values from the multiple columns of an expression.  (i.e It allows multiple columns)

i.e. It returns the sum of an expression evaluated for each row in a table.
Syntax: SUMX(<Table>, <Expression>)

Ex: SumX.Salary= SUMX(Emp, Emp[Sal]+Emp[Comm])

-MIN(): It returns the smallest numeric value from a single column.

Ex: MinSal = MIN(Emp[SAL])

-MINX(): It returns the smallest numeric value from multiple columns of an expression.

Ex: MinX.Salary= MINX(Emp, Emp[Sal]+Emp[Comm])

-MAX(): It returns the largest numeric value from a single column.

Ex: MaxSal = MAX(Emp[SAL])

-MAXX(): It returns the largest numeric value from multiple columns of an expression.

Ex: MaxX.Salary= MAXX(Emp, Emp[Sal]+Emp[Comm])

-COUNT(): It counts the No. of cells in a Single Column.

Ex: Count.Comm= COUNT(Emp[COMM])

-COUNTX(): It counts the No. of cells from multiple columns of an expression.

Ex: CountX.TotSal= COUNTX(Emp, Emp[Sal]+Emp[Comm])


-AVERAGE(): It returns the Average value from a single column.

Ex: Avg.Sal = AVERAGE(Emp[SAL])

-AVERAGEX(): It returns the Average value from multiple columns of an expression.

Ex: AvgX.Sal= AVERAGEX(Emp, Emp[Sal]+Emp[Comm])

-COUNTROWS(): Counts Total rows in a table.

Ex: TotRows = COUNTROWS(Emp)

-COUNTBLANK(): It Counts No.of blank cells in a Column.

Ex: Blank.Comm= COUNTBLANK(Emp[COMM])

-- RANKX(): It will be used for Rankings.

Ex:- Rank the Salaries for Each Employees.

Syntax: RANKX(Table, Exp[ , Val], [ , ORDER], [ , TIES], .....)

ORDER(): Either in Ascending or Descending Order --> Default is Desc.

Asc --> Least Value 1st Rank, 2nd Least Value 2nd Rank and so on...

Desc --> Largest Value 1st Rank, 2nd Largest Value 2nd Rank and so on...

TIES(): Either Dense or Skip --> Default is Skip.

Dense--> It will not Skip b/w Rank Numbers.

Skip--> It will Skip b/w Rank Numbers.

Note: Optional Arguments might be skipped by placing an empty comma (,) in Argument List.

i.e.  Sal.RankX= RANKX(Emp, Emp[Sal], , , Dense)


------- Time Intelligence Functions

	Time Intelligence means doing calculations over periods of time or date. 
	Time Intelligence Functions will need have a DATE column to perform the calculations.

	This Date column must contain 1)unique dates, 2)no null and 3) contiguous date values to get the accurate results.

	You will find a Date Column in Dimension Date Table Which will Satify the above 3 Conditions.

	To make DAX Time Intelligence functions work properly set Dimension Date Table as “Mark as date table”.

When you specify your own date table, Power BI Desktop performs the following validations of that column and its data, to ensure that the data
	contains unique values
	contains no null values
	contains contiguous date values (from beginning to end)
	if it is a Date/Time data type, it has the same timestamp across each value
